# H1 실험 설계서: 중추 흥분성 뉴런 GPR75의 체중 필요성과 섭식 기여 분리
- 가설: docs/gpr75/hypotheses.md H1 / 이슈 #12 / 근거 R001, R017, R018, R019, R023, R012, R015
## 목적
vGlut2 뉴런 GPR75 결손의 체중 보호가 섭식 차이로 설명되는지, 에너지소비로 설명되는지 분리한다.
## 모델계
- 마우스: Gpr75 조건부 allele(flox)와 Slc17a6(vGlut2) 계열 Cre 구동체 교배(R018과 유사). 사용 가능 계통과 입수 경로는 미확인이며 R018 방법 절에서 확인해야 한다.
- 비교군: GABA 뉴런 Cre(음성 대조, R018), AgRP-Cre(R023의 효과가 작았던 집단).
## 처치와 대조군
- 군: 결손 / flox 단독 / Cre 단독 / 야생형. 일반 사료와 고지방 식이 각각.
- 쌍먹이(pair-feeding) 대조: 결손군의 섭식량에 맞춰 대조군에 먹이를 제공한다. 체중 효과가 남으면 섭식 외 기전.
## 측정 지표
주 1회 체중, 자동 급이 장치에 의한 섭식량(수동 측정과 병행해 방법 차이 확인), 체성분(NMR), 간접열량계(VO2, VCO2, 활동), 포도당 내성.
## 예상 결과와 해석
- 결손군 체중↓ + 섭식↓ + 쌍먹이 후 체중 차이 소실 → 섭식 기전(R012, R015, R018 지지).
- 체중↓ + 섭식 변화 없음 + 에너지소비 변화 → R023, R019 지지, H8로 연결.
- 체중 차이 없음 → H1 기각.
## 필요한 시약과 자원
조건부 allele 마우스, Cre 계통, 자동 급이·간접열량계 설비, NMR 체성분 장비. 외주 시 이 설비를 갖춘 기관이 필요.

## 선점 가능성과 한계
R018·R017·R019가 선행했고 2026년 경쟁이 치열하다. 한계: 마우스 계통 입수 경로와 암컷 짝급이 선례가 미확인이다.

## 공통 항목
- 성별: 암수 모두 포함하고 성별을 사전 지정 층화 변수로 둔다(R023, R024, R026이 성별 이질성을 시사).
- 표본 수 가정: 표준편차(SD)는 선행 논문 본문에서 찾지 못했다(평균±SEM, 값은 그림 속, 미확인). 따라서 효과 크기(d)를 가정해 계산한 값이다. 발표 연구의 군당 표본 수는 대략 8~10마리(R013 7~11, R015 9, R019 10, R023 8, R024 8)다. 큰 효과(d≈1.2, 검정력 0.8, α=0.05)는 군당 약 11마리이고 탈락 20%를 더해 14마리다. 작은 효과(체중 10~12% 감소, R023 AgRP KO 수준, d≈0.8 가정)는 군당 약 25마리이고 탈락 20%를 더해 30마리가 필요하다. 그림 원자료(source data)로 SD를 얻으면 다시 계산한다.
- 무작위 배정, 사육 상자 단위 교란 통제, 평가자 눈가림. 모든 지표는 사전 등록한 분석 계획을 따른다.
- 식이·연령·계통·사육 온도는 기록하고 군 간 동일하게 맞춘다. 연구 간 상충(R017 vs R024 등)의 원인 후보다.
- 이 문서는 설계까지다. 실제 실험 실행(동물 윤리 승인, 시약 구매, 외주)은 Mini의 확인 후에만 진행한다. 이 프로젝트의 제약(공개 데이터, iMac CPU)상 자체 실험 수행은 범위 밖이며, 설계서는 외부 수행 또는 후속 연구용이다.
- 합성·제조·투약 지침은 포함하지 않는다.
