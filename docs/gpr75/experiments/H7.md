# H7 실험 설계서: 성체에서의 억제가 기존 비만을 되돌리는가
- 가설: H7 / 이슈 #12 / 근거 R019, R021, R023
## 목적
이미 비만이 된 성체에서 GPR75 억제가 체중 감소를 일으키는지, 보상 반응이 있는지 확인한다.
## 모델계
고지방 식이로 비만을 만든 성체 마우스 + 시기 지정 가능한 유도 결손(R019와 동일 계열 후보).
## 처치와 대조군
- 결손 유도군 / 유도 처치 대조(Cre 없음) / 유도 없음. 암수 모두.
- 유도 후 식이 유지군과 일반 식이 전환군 비교.
- 약물 억제는 저해제가 없어 포함하지 않는다. 대안 모달리티 검토는 별도 문헌 조사 이후.
## 측정 지표
유도 후 체중 궤적(장기 추적), 지방량·제지방(R019의 제지방 보존 확인), 섭식, 에너지소비, 포도당 내성, 장 지질 흡수 지표(H9), 체중 재상승 여부.
## 예상 결과와 해석
- 체중·지방량 감소 + 제지방 보존 → 치료 타당성 지지. 감소 후 재상승 → 보상 반응.
- 감소 없음 → R019 결과가 예방에만 해당.
## 필요한 시약과 자원
유도 결손 계통, 장기 사육 설비, NMR, 간접열량계.

## 공통 항목
- 성별: 암수 모두 포함하고 성별을 사전 지정 층화 변수로 둔다(R023, R024, R026이 성별 이질성을 시사).
- 표본 수 가정: 효과 크기 d=1.2, α=0.05, 검정력 0.8의 2군 비교에서 군당 약 11~12마리(성별별). 탈락 20%를 가산해 군당 14마리를 기본값으로 둔다. 실제 변동성(SD)은 선행 논문 전문에서 확인해 다시 계산해야 한다(미확인).
- 무작위 배정, 사육 상자 단위 교란 통제, 평가자 눈가림. 모든 지표는 사전 등록한 분석 계획을 따른다.
- 식이·연령·계통·사육 온도는 기록하고 군 간 동일하게 맞춘다. 연구 간 상충(R017 vs R024 등)의 원인 후보다.
- 이 문서는 설계까지다. 실제 실험 실행(동물 윤리 승인, 시약 구매, 외주)은 Mini의 확인 후에만 진행한다. 이 프로젝트의 제약(공개 데이터, iMac CPU)상 자체 실험 수행은 범위 밖이며, 설계서는 외부 수행 또는 후속 연구용이다.
- 합성·제조·투약 지침은 포함하지 않는다.
