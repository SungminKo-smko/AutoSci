# H7 실험 설계서: 성체 억제와 비만 역전 (H7a 유전적 / H7b 약물)
- 가설: hypotheses.md H7a(중~약), H7b(미확인) / 이슈 #12, #19 / 근거 R019, R017, R021, R043, R039, R035, R036, R023
## 목적
(a) 비만이 이미 생긴 성체에서 유전적 GPR75 억제가 체중을 줄이는지를 올바른 대조로 재검증한다. (b) 약물 등 비유전적 억제 수단을 쓰기 전에, 그 수단이 GPR75 선택적인지 먼저 검증한다.
## H7a: 유전적 성체 억제
### 모델계
HFD로 비만을 만든 성체 마우스 + 시기 지정 가능한 유도 결손(R019 계열). 암수 모두.
### 처치와 대조군
- 유도 결손군 / **Cre-음성 + 유도 처치 대조**(유도 처치 자체의 체중 효과를 제거, R019 지적) / 유도 처치 없는 군 / 식이 전환 대조.
- 체중 감소는 기저선 보정 값과 Cre-음성 처치 대조 보정 값을 모두 보고.
### 측정 지표
체중 궤적, 체성분(지방량·제지방, 제지방 보존 R019 vs 감소 R017 확인), 섭식(암수 따로, R019의 성별 차이 확인), 에너지소비(체중·제지방 공변량 ANCOVA), 장 지질 흡수(H9, R023 안전성 신호), 뇌 mRNA 감소율, 결손 효율.
### 예상 결과와 해석
- 대조 보정 후에도 체중·지방량 감소 + 제지방 보존 → 치료 타당성 지지(R019 재현). 대조 보정 시 효과가 사라지면 타목시펜 교란이다.
- 섭식이 성별별로 다르면(수컷 변화 없음, 암컷 감소) H1·H6 성별 가설과 연결.
## H7b: 약물 등 비유전적 억제 (도구 검증 선행)
### 현재 상태
- 약물 억제가 비만을 개선했다는 보고를 찾지 못했다(미확인, 없음 단정 아님).
- "AAA"(R039)는 20-HETE 수용체 길항제이고 GPR75 선택성 자료가 없다. R035, R036에서의 사용은 비만 모델이 아니다. 따라서 H7b의 근거가 아니라 **후보 도구**로만 취급한다.
- R021(포켓 폐쇄)과 R043(프리프린트: 포켓 주장)이 상충해, 소분자 결합 가능성 자체가 불확실하다.
### 도구 검증 설계 (on-target 시험)
- GPR75 knockout 세포 또는 KO 마우스에서 억제 수단의 효과가 사라지는지 확인한다. 효과가 KO에서도 남으면 비표적 효과.
- 20-HETE 생성 경로와의 교란 분리: 20-HETE 수준을 측정하고 GPR75 의존 반응과 비의존 반응(R008)을 대조한다.
- 선택성이 확인된 수단에 한해 비만 성체 모델에서 유전적 억제(H7a)와 같은 지표로 비교 실험을 설계한다. 비교 설계는 선택성 확인 전에는 확정하지 않는다.
- 이 설계서는 용량·투여 일정을 정하지 않는다(문서 범위 밖).
### 예상 결과와 해석
- KO에서 효과 소실 + 비만 성체에서 체중 감소 → 약물 억제 타당성 지지. KO에서도 효과 → 비표적. 선택성 확인 불가 → H7b 보류.
## 필요한 시약과 자원
유도 결손 계통, Cre-음성 대조, 장기 사육·NMR·열량계, KO 조직. 약물 후보는 선택성 자료 확보 후 결정.

## 선점 가능성과 한계
R019(기업 소속 저자)가 선행해 선점·IP 가능성이 있다(특허는 일부만 검색). 한계: 약물 억제 도구의 선택성이 미확인이다.

## 공통 항목
- 성별: 암수 모두 포함하고 성별을 사전 지정 층화 변수로 둔다(R023, R024, R026이 성별 이질성을 시사).
- 표본 수 가정: 표준편차(SD)는 선행 논문 본문에서 찾지 못했다(평균±SEM, 값은 그림 속, 미확인). 따라서 효과 크기(d)를 가정해 계산한 값이다. 발표 연구의 군당 표본 수는 대략 8~10마리(R013 7~11, R015 9, R019 10, R023 8, R024 8)다. 큰 효과(d≈1.2, 검정력 0.8, α=0.05)는 군당 약 11마리이고 탈락 20%를 더해 14마리다. 작은 효과(체중 10~12% 감소, R023 AgRP KO 수준, d≈0.8 가정)는 군당 약 25마리이고 탈락 20%를 더해 30마리가 필요하다. 그림 원자료(source data)로 SD를 얻으면 다시 계산한다.
- 무작위 배정, 사육 상자 단위 교란 통제, 평가자 눈가림. 모든 지표는 사전 등록한 분석 계획을 따른다.
- 식이·연령·계통·사육 온도는 기록하고 군 간 동일하게 맞춘다. 연구 간 상충(R017 vs R024 등)의 원인 후보다.
- 이 문서는 설계까지다. 실제 실험 실행(동물 윤리 승인, 시약 구매, 외주)은 Mini의 확인 후에만 진행한다. 이 프로젝트의 제약(공개 데이터, iMac CPU)상 자체 실험 수행은 범위 밖이며, 설계서는 외부 수행 또는 후속 연구용이다.
- 합성·제조·투약 지침은 포함하지 않는다.
