# H3 실험 설계서: GPR75의 G단백질 결합 판별 (Gq 대 Gi, 구성적 활성)
- 가설: hypotheses.md H3(약, 상충) / 이슈 #12, #19 / 근거 R005, R007, R022, R035, R021, R041, R042, R025
## 목적
Gq 보고(R005, R022, R035)와 Gi·구성적 활성 보고(R041, R042 프리프린트, R025)를 같은 세포계·같은 판독으로 직접 비교해 GPR75가 어떤 G단백질과 결합하는지 정한다.
## 모델계
- 세포: GPR75를 낮은 발현으로 도입한 숙주 세포(HEK293 계열)와 GPR75 knockout 세포. 내인성 발현 뉴런 세포(R004의 SH-SY5Y)와 시상하부 유래 뉴런 배양(활꼴핵 vGlut2 뉴런, R035 맥락)은 확인 단계로 사용.
- 발현량 대조: 구성적 활성은 발현량에 비례해 커질 수 있으므로 발현 수준(표면 발현)을 정량해 단계별로 비교한다.
## 처치와 대조군
- 야생형, Thr212 변이(R007), 구조 기반 신호 불능 변이(R021, DRY→HRL 부위), 빈 벡터.
- G단백질 의존성: Gi 경로 차단(백일해 독소 처리)과 Gq 경로 차단(Gq 억제제)을 각각 적용.
- 양성 대조: 알려진 Gq 결합 수용체와 알려진 Gi 결합 수용체를 같은 플레이트에 둔다.
- 리간드: 20-HETE, CCL5(H4, H5와 연결)를 첨가한 조건과 무첨가(기저 신호) 조건 모두.
## 측정 지표
- Gq 판독: IP1 축적, 세포 내 Ca2+.
- Gi 판독: cAMP 감소(포스콜린 자극 하), GTPγS 결합, G단백질 BRET 패널(Gq/Gi/G12/13 등 동시).
- 기저 신호(구성적 활성): 리간드 없이 발현량 의존 신호 증가.
- 하류: AKT/ERK 인산화.
## 예상 결과와 해석
- Gq 지표만 상승 → Gq 보고 지지. Gi 지표만 상승·백일해 독소 민감 → R041, R042 지지. 둘 다 → 맥락 의존 이중 결합.
- 리간드 무첨가에서 신호가 있고 리간드 효과가 없으면 구성적 활성(R041)이며, H4, H5의 전제(리간드 활성화)가 약해진다.
- 뉴런에서만 Gq 신호가 나타나면 R035와 일치하며, 숙주 세포 결과가 뉴런을 대변하지 못함을 시사.
## 필요한 시약과 자원
GPR75 구성체와 변이체, 신호 측정 키트(IP1, cAMP), BRET 기반 G단백질 센서, 백일해 독소, 플레이트 리더. R042는 링크가 브라우저 확인이 필요해 방법 비교는 보류.

## 선점 가능성과 한계
독립 연구실(R041, R042 프리프린트)이 같은 질문을 다루고 있어 선점 가능성이 있다. 한계: 프리프린트 결론은 미확인이며 숙주 세포 과발현 결과가 뉴런 생리를 대변하지 못할 수 있다.

## 공통 항목
- 성별: 암수 모두 포함하고 성별을 사전 지정 층화 변수로 둔다(R023, R024, R026이 성별 이질성을 시사).
- 표본 수 가정: 표준편차(SD)는 선행 논문 본문에서 찾지 못했다(평균±SEM, 값은 그림 속, 미확인). 따라서 효과 크기(d)를 가정해 계산한 값이다. 발표 연구의 군당 표본 수는 대략 8~10마리(R013 7~11, R015 9, R019 10, R023 8, R024 8)다. 큰 효과(d≈1.2, 검정력 0.8, α=0.05)는 군당 약 11마리이고 탈락 20%를 더해 14마리다. 작은 효과(체중 10~12% 감소, R023 AgRP KO 수준, d≈0.8 가정)는 군당 약 25마리이고 탈락 20%를 더해 30마리가 필요하다. 그림 원자료(source data)로 SD를 얻으면 다시 계산한다.
- 무작위 배정, 사육 상자 단위 교란 통제, 평가자 눈가림. 모든 지표는 사전 등록한 분석 계획을 따른다.
- 식이·연령·계통·사육 온도는 기록하고 군 간 동일하게 맞춘다. 연구 간 상충(R017 vs R024 등)의 원인 후보다.
- 이 문서는 설계까지다. 실제 실험 실행(동물 윤리 승인, 시약 구매, 외주)은 Mini의 확인 후에만 진행한다. 이 프로젝트의 제약(공개 데이터, iMac CPU)상 자체 실험 수행은 범위 밖이며, 설계서는 외부 수행 또는 후속 연구용이다.
- 합성·제조·투약 지침은 포함하지 않는다.
