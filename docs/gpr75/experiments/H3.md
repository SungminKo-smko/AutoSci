# H3 실험 설계서: Gq-PLC-Ca2+ 신호의 뉴런 내 매개
- 가설: H3 / 이슈 #12 / 근거 R005, R007, R022, R021, R025
## 목적
GPR75가 뉴런 맥락에서 Gq 경로로 신호하는지, 아니면 Gi(R025)나 다른 경로인지 확인한다.
## 모델계
- 세포: GPR75 발현이 낮은 숙주 세포(HEK293 계열)에 GPR75 도입, 그리고 내인성 발현 뉴런 세포(SH-SY5Y, R004)와 비교.
- GPR75 knockout 세포를 대조로 사용.
## 처치와 대조군
- 야생형 GPR75, Thr212 변이체(R007), 구조 기반 신호 불능 변이체(R021, DRY→HRL 부위) 비교.
- G단백질 의존성 대조: Gq 경로 억제와 Gi 경로 억제를 각각 적용해 어느 쪽에서 차단되는지 본다(억제 수단 선택은 문헌 확인 필요).
- 양성 대조: 이미 알려진 Gq 결합 수용체.
## 측정 지표
IP1 축적, 세포 내 Ca2+ 이미징, cAMP 변화, AKT/ERK 인산화.
## 예상 결과와 해석
- Gq 억제로 신호 소실 → H3 지지. Gi 억제로 소실 → 간(R025) 경로와 유사, H3 수정 필요.
- 리간드 없이 기저 신호(구성적 활성)가 나타나면 리간드 가설(H4, H5)의 전제 변화.
## 필요한 시약과 자원
GPR75 발현 구성체와 변이체, 신호 측정 키트, 형광 Ca2+ 지시자, 플레이트 리더 또는 이미징 설비.

## 공통 항목
- 성별: 암수 모두 포함하고 성별을 사전 지정 층화 변수로 둔다(R023, R024, R026이 성별 이질성을 시사).
- 표본 수 가정: 효과 크기 d=1.2, α=0.05, 검정력 0.8의 2군 비교에서 군당 약 11~12마리(성별별). 탈락 20%를 가산해 군당 14마리를 기본값으로 둔다. 실제 변동성(SD)은 선행 논문 전문에서 확인해 다시 계산해야 한다(미확인).
- 무작위 배정, 사육 상자 단위 교란 통제, 평가자 눈가림. 모든 지표는 사전 등록한 분석 계획을 따른다.
- 식이·연령·계통·사육 온도는 기록하고 군 간 동일하게 맞춘다. 연구 간 상충(R017 vs R024 등)의 원인 후보다.
- 이 문서는 설계까지다. 실제 실험 실행(동물 윤리 승인, 시약 구매, 외주)은 Mini의 확인 후에만 진행한다. 이 프로젝트의 제약(공개 데이터, iMac CPU)상 자체 실험 수행은 범위 밖이며, 설계서는 외부 수행 또는 후속 연구용이다.
- 합성·제조·투약 지침은 포함하지 않는다.
