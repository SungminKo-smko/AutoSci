# H2 실험 설계서: 시상하부 일차섬모 위치와 Adcy3 의존성
- 가설: H2 / 이슈 #12 / 근거 R015, R016
## 목적
GPR75 효과가 섬모 위치와 Adcy3에 의존하는지 검증한다.
## 모델계
- 세포: 섬모를 형성하는 시상하부 유래 뉴런 세포주 또는 일차 배양(적합 세포주는 미확인).
- 마우스: 섬모 표적 신호를 잃게 한 GPR75 변이체 knock-in(R015의 섬모 표적 모티프 정보 필요, 미확인).
## 처치와 대조군
- 세포: 야생형 GPR75, 섬모 표적 소실 변이체, Adcy3 녹다운 조합의 2×2 배치.
- 마우스: 변이체 knock-in / 야생형 / Adcy3 이형접합 배경에서의 GPR75 결손.
## 측정 지표
섬모 국재(면역형광, 섬모 마커 ARL13B 공동염색), 섬모 cAMP(센서 기반), 마우스는 체중·섭식·체성분.
## 예상 결과와 해석
- 변이체가 야생형처럼 행동하면 섬모 위치는 필수가 아님 → H2 기각.
- 섬모 소실 시 신호·표현형 소실, Adcy3 약화 시 효과 소실 → H2 지지.
- 렙틴 경로 의존(ob/ob에서 효과 없음, R015) 여부는 별도 대조(ob/ob 배경)로 구분.
## 필요한 시약과 자원
섬모 마커 항체, cAMP 센서, 변이체 발현 구성체, 공초점 현미경. R015 보충자료 확인 필요.

## 공통 항목
- 성별: 암수 모두 포함하고 성별을 사전 지정 층화 변수로 둔다(R023, R024, R026이 성별 이질성을 시사).
- 표본 수 가정: 효과 크기 d=1.2, α=0.05, 검정력 0.8의 2군 비교에서 군당 약 11~12마리(성별별). 탈락 20%를 가산해 군당 14마리를 기본값으로 둔다. 실제 변동성(SD)은 선행 논문 전문에서 확인해 다시 계산해야 한다(미확인).
- 무작위 배정, 사육 상자 단위 교란 통제, 평가자 눈가림. 모든 지표는 사전 등록한 분석 계획을 따른다.
- 식이·연령·계통·사육 온도는 기록하고 군 간 동일하게 맞춘다. 연구 간 상충(R017 vs R024 등)의 원인 후보다.
- 이 문서는 설계까지다. 실제 실험 실행(동물 윤리 승인, 시약 구매, 외주)은 Mini의 확인 후에만 진행한다. 이 프로젝트의 제약(공개 데이터, iMac CPU)상 자체 실험 수행은 범위 밖이며, 설계서는 외부 수행 또는 후속 연구용이다.
- 합성·제조·투약 지침은 포함하지 않는다.
