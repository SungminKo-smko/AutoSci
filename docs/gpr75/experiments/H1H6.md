# H1+H6 통합 실험 설계서: 중추·말초 조직별 결손의 병렬 비교 (섭식·에너지소비 분리, 암수)
- 가설: hypotheses.md H1(중추 필요성 중, 섭식 기전 약·상충), H6(조직·성별 약·상충), H8 / 이슈 #12, #19 / 근거 R001, R013, R015, R017, R018, R019, R023, R024, R025, R035
- 참신성: novelty.md 기준 H1 5/10, H6 6/10. 기여는 새 현상이 아니라 **상충을 해소하는 통제된 비교**다.
## 목적
같은 유전적 배경·식이·연령·사육 조건에서 조직별 결손의 체중 효과를 병렬로 비교하고, 섭식과 에너지소비를 암수 각각에서 인과적으로 분리한다. 구체적으로 다음 상충을 가른다.
1. 섭식 감소가 기전인가: R015(짝급이로 지지) vs R013, R023, R024(섭식 차이 없음), R019(수컷 없음, 암컷 감소).
2. 지방세포 결손이 보호하는가: R024(암컷만) vs R017(미미).
3. 에너지소비 방향: R023(감소) vs R024(원시 증가, 보정 후 소실) vs R013.
4. 최소 회로: vGlut2 전체(R018) vs AgRP(R023, 효과 작음) vs 활꼴핵 vGlut2(R035 맥락).
## 모델계
- 하나의 Gpr75 조건부(flox) allele를 모든 군에 공통으로 쓰고 Cre 구동체만 바꾼다. 같은 교배 배경, 같은 식이 공급처, 같은 사육 시설.
- Cre 구동체(후보): 흥분성 뉴런(vGlut2), AgRP 뉴런, 지방세포, 간세포, 장 상피, 췌도 β세포. 활꼴핵 국소 결손(바이러스 Cre)을 vGlut2 하위집단 검증으로 추가.
- 구동체별 마우스 입수 경로, 재조합 효율과 특이성은 미확인이다. 각 구동체의 결손 효율(mRNA 감소율)을 보고 지표에 포함한다(R019의 63~85% 선례).
- 음성 대조 후보: GABA 뉴런 구동체(R018).
## 처치와 대조군
- 모든 구동체 군에 flox 단독, Cre 단독 대조를 둔다. 암수를 모두 넣고 성별×유전자형 상호작용을 사전 가설로 둔다.
- 식이: 일반 사료와 고지방 식이(HFD).
- **짝급이 군**: 결손군의 섭식량에 맞춰 대조군에 급이(R015 방식). 암수 모두에 적용해 R015의 수컷 한정을 보완한다.
- **두 시점**: 체중이 갈리기 전(HFD 2주 전후, R023 시점)과 분기 후(HFD 14주 전후, R024 시점)에 같은 개체에서 에너지소비를 측정한다. 사육 온도는 군 간 동일하게 기록한다.
## 측정 지표
- 체중 궤적(주 1회), 체성분(NMR: 지방량·제지방).
- 섭식: 자동 급이 장치와 수동 측정을 병행해 방법 차이 확인(암수 따로).
- 에너지소비·RER·활동: 간접열량계. 공변량(체중, 제지방)을 **사전 등록**하고 원시값과 보정값을 모두 보고. 단순 체중 나누기 금지.
- 포도당 내성, 간 지방(R025), 분변 지질(H9).
- 결손 효율(조직별 mRNA/단백질).
## 분석 계획 (사전 등록)
- 주 분석: 군 × 성별 이원 분산분석(상호작용 항 포함), 에너지소비는 ANCOVA. 다중 비교 보정.
- 판정 기준을 미리 정한다: 짝급이 후 체중 차이가 남으면 섭식 외 기전, 소실되면 섭식 기전.
## 예상 결과와 해석
- 뉴런 결손만 보호, 섭식↓, 짝급이 후 차이 소실 → 중추-섭식 모델(R015, R018 지지).
- 체중 보호 + 섭식 변화 없음 + 보정 EE 차이 → 에너지소비 기전(H8 지지).
- 보정 EE 차이 없음 + 시점별 방향 차이만 있음 → R023/R024 불일치는 방법 차이로 설명.
- 지방세포 결손이 암컷에서만 보호 → R024 지지(성별 의존), 수컷·암컷 모두 무효 → R017 지지.
- 어느 단일 조직도 전신 효과를 설명 못하면 다기관 합산 효과(R023의 해석과 일치).
- 췌도 결손은 발표 보고가 없어 결과가 어떻든 새 정보다(PubMed 검색 기준, 미확인).
## 표본 수
- 큰 효과 군(뉴런 전체, 지방세포 암컷 등 평균 차이 큼): 군당 14마리(성별별)로 시작. R024는 평균 차이 >50% 가정 8마리/성이었다.
- 작은 효과 군(AgRP 등 체중 10~12% 감소 수준): 군당 약 30마리(성별별, d≈0.8 가정, 탈락 20% 포함). 총 사육 규모가 커서 구동체를 단계적으로 수행(뉴런 → 지방세포 → 간·장 → 췌도)하는 것을 권한다.
- SD는 미확인이다. 그림 원자료를 받으면 재계산한다.
## 필요한 시약과 자원
Gpr75 조건부 allele 마우스와 Cre 계통 여러 개, 자동 급이·간접열량계·NMR, 장기 사육 공간. 자체 수행 불가 시 외부 연구실 협력 필요.
## 선점 가능성과 한계
R018, R017, R019, R023, R024가 부분적으로 선행했으나, 같은 배경·병렬·암수 짝급이·두 시점 EE를 한 연구로 묶은 보고는 PubMed에서 찾지 못했다(미확인). 한계: 규모가 크고 비용이 높으며, 구동체 특이성과 계통 입수가 미확인이다.

## 공통 항목
- 성별: 암수 모두 포함하고 성별을 사전 지정 층화 변수로 둔다(R023, R024, R026이 성별 이질성을 시사).
- 표본 수 가정: 표준편차(SD)는 선행 논문 본문에서 찾지 못했다(평균±SEM, 값은 그림 속, 미확인). 따라서 효과 크기(d)를 가정해 계산한 값이다. 발표 연구의 군당 표본 수는 대략 8~10마리(R013 7~11, R015 9, R019 10, R023 8, R024 8)다. 큰 효과(d≈1.2, 검정력 0.8, α=0.05)는 군당 약 11마리이고 탈락 20%를 더해 14마리다. 작은 효과(체중 10~12% 감소, R023 AgRP KO 수준, d≈0.8 가정)는 군당 약 25마리이고 탈락 20%를 더해 30마리가 필요하다. 그림 원자료(source data)로 SD를 얻으면 다시 계산한다.
- 무작위 배정, 사육 상자 단위 교란 통제, 평가자 눈가림. 모든 지표는 사전 등록한 분석 계획을 따른다.
- 식이·연령·계통·사육 온도는 기록하고 군 간 동일하게 맞춘다. 연구 간 상충(R017 vs R024 등)의 원인 후보다.
- 이 문서는 설계까지다. 실제 실험 실행(동물 윤리 승인, 시약 구매, 외주)은 Mini의 확인 후에만 진행한다. 이 프로젝트의 제약(공개 데이터, iMac CPU)상 자체 실험 수행은 범위 밖이며, 설계서는 외부 수행 또는 후속 연구용이다.
- 합성·제조·투약 지침은 포함하지 않는다.
