# H4 실험 설계서: 20-HETE의 GPR75 의존성 독립 검증
- 가설: H4 / 이슈 #12 / 근거 R005, R007, R008, R009, R027~R029
## 목적
20-HETE 효과가 GPR75 의존적인지를 연구실 독립적으로, 비만 관련 세포계에서 검증한다.
## 모델계
- 세포: GPR75 야생형 발현과 knockout 쌍. 뉴런 유래 세포, 지방세포, 필요시 R008의 혈소판 대조.
- 마우스: Gpr75 결손 마우스와 야생형(R012 계통 후보).
## 처치와 대조군
- 20-HETE 처리 대 비활성 지방산 유사체 대조, GPR75 존재 대 부재.
- 생성 억제 조건(CYP4A/4F 계열 억제)과 외부 첨가 조건 비교.
- 결합 직접 측정: 정제 GPR75에 대한 표면 플라즈몬 공명 또는 대안 결합 분석(R007과 비교).
## 측정 지표
IP1/Ca2+ 반응, 결합 친화도(KD), 뇌 조직의 20-HETE 내인성 수준(질량분석), 결손 마우스 표현형과 억제 마우스의 비교.
## 예상 결과와 해석
- KO 세포에서 반응 소실, 억제 시 표현형 모사 → H4 지지.
- KO에서도 반응 유지 → R008 지지, H4 기각.
- 뇌 내 20-HETE가 검출 한계 미만 → 비만 경로의 리간드로는 부적합.
## 필요한 시약과 자원
20-HETE 표준물(상용 구매 가능 여부는 확인 필요), 결합 분석 장비, 질량분석. 독립성을 위해 R005와 다른 기관 수행을 권장.

## 공통 항목
- 성별: 암수 모두 포함하고 성별을 사전 지정 층화 변수로 둔다(R023, R024, R026이 성별 이질성을 시사).
- 표본 수 가정: 효과 크기 d=1.2, α=0.05, 검정력 0.8의 2군 비교에서 군당 약 11~12마리(성별별). 탈락 20%를 가산해 군당 14마리를 기본값으로 둔다. 실제 변동성(SD)은 선행 논문 전문에서 확인해 다시 계산해야 한다(미확인).
- 무작위 배정, 사육 상자 단위 교란 통제, 평가자 눈가림. 모든 지표는 사전 등록한 분석 계획을 따른다.
- 식이·연령·계통·사육 온도는 기록하고 군 간 동일하게 맞춘다. 연구 간 상충(R017 vs R024 등)의 원인 후보다.
- 이 문서는 설계까지다. 실제 실험 실행(동물 윤리 승인, 시약 구매, 외주)은 Mini의 확인 후에만 진행한다. 이 프로젝트의 제약(공개 데이터, iMac CPU)상 자체 실험 수행은 범위 밖이며, 설계서는 외부 수행 또는 후속 연구용이다.
- 합성·제조·투약 지침은 포함하지 않는다.
