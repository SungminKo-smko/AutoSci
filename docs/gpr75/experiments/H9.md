# H9 실험 설계서: 장 지질 흡수와 성별
- 가설: H9 / 이슈 #12 / 근거 R023
## 목적
R023의 수컷 장 지질 흡수 장애를 독립적으로 재현하고 장 자율 효과인지 확인한다.
## 모델계
전신 KO, 장 상피 특이 KO(R023에서 보호 재현 실패), 야생형. 암수 모두.
## 처치와 대조군
식이 지질 함량을 동일하게 맞춘 군, 지질 부하 시험군.
## 측정 지표
분변 지질 배설량, 지질 부하 후 혈중 중성지방 곡선, 장 조직 지질 수송체 발현, 담즙산 프로필(간접 기전 확인).
## 예상 결과와 해석
- 전신 KO 수컷에서만 배설 증가, 장 특이 KO에서는 없음 → 간접(비장 자율) 효과, 부작용 위험 신호로 해석.
- 모든 군에서 차이 없음 → H9 기각.
## 필요한 시약과 자원
대사 케이지, 지질 정량 키트, 질량분석(담즙산).

## 선점 가능성과 한계
R023 단일 보고라 선점 위험은 낮으나 독립 재현이 필요하다. 한계: 간접 기전과 구분이 어렵다.

## 공통 항목
- 성별: 암수 모두 포함하고 성별을 사전 지정 층화 변수로 둔다(R023, R024, R026이 성별 이질성을 시사).
- 표본 수 가정: 표준편차(SD)는 선행 논문 본문에서 찾지 못했다(평균±SEM, 값은 그림 속, 미확인). 따라서 효과 크기(d)를 가정해 계산한 값이다. 발표 연구의 군당 표본 수는 대략 8~10마리(R013 7~11, R015 9, R019 10, R023 8, R024 8)다. 큰 효과(d≈1.2, 검정력 0.8, α=0.05)는 군당 약 11마리이고 탈락 20%를 더해 14마리다. 작은 효과(체중 10~12% 감소, R023 AgRP KO 수준, d≈0.8 가정)는 군당 약 25마리이고 탈락 20%를 더해 30마리가 필요하다. 그림 원자료(source data)로 SD를 얻으면 다시 계산한다.
- 무작위 배정, 사육 상자 단위 교란 통제, 평가자 눈가림. 모든 지표는 사전 등록한 분석 계획을 따른다.
- 식이·연령·계통·사육 온도는 기록하고 군 간 동일하게 맞춘다. 연구 간 상충(R017 vs R024 등)의 원인 후보다.
- 이 문서는 설계까지다. 실제 실험 실행(동물 윤리 승인, 시약 구매, 외주)은 Mini의 확인 후에만 진행한다. 이 프로젝트의 제약(공개 데이터, iMac CPU)상 자체 실험 수행은 범위 밖이며, 설계서는 외부 수행 또는 후속 연구용이다.
- 합성·제조·투약 지침은 포함하지 않는다.
